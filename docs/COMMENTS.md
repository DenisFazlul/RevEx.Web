# Комментарии

Набор — самостоятельное обсуждение с названием, ID, создателем и датой создания.
Комментарий принадлежит ровно одному набору: ID, ID набора, текст, ID и имя автора,
дата создания UTC и дата редактирования UTC (null до первого изменения).
Автор определяется из токена; передать чужого автора в запросе нельзя.
Все маршруты требуют авторизации. Наборы и комментарии доступны всем
авторизованным пользователям. Редактировать и удалять комментарий может только
его автор; чужой или отсутствующий комментарий возвращает 404.

- GET /api/comment-sets?offset=0&limit=50 — список наборов.
- POST /api/comment-sets — создать набор: { "name": "Обсуждение" }.
- GET /api/comment-sets/{setId} — получить набор.
- GET /api/comment-sets/{setId}/comments?offset=0&limit=50 — комментарии по времени создания.
- POST /api/comment-sets/{setId}/comments — добавить: { "text": "Комментарий" }.
- PUT /api/comment-sets/{setId}/comments/{id} — изменить: { "text": "Новый текст" }.
- DELETE /api/comment-sets/{setId}/comments/{id} — удалить свой комментарий.

Название: 1–200 символов; текст: 1–10000 символов, пробельные строки запрещены.
Размер страницы: 1–200. Таблицы PostgreSQL comment_sets и comments создаются
миграцией AddComments при инициализации БД. Связь защищена внешним ключом.
