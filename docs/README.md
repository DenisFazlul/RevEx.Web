## Экосистема

| Репозиторий | Ответственность |
| --- | --- |
| [RevEx.Web](https://github.com/DenisFazlul/RevEx.Web) | API, серверные данные, веб-панель администратора и вход Keycloak. |
| [RevEx.Desktop](https://github.com/DenisFazlul/RevEx.Desktop) | Основное рабочее место: каталог, редактирование, файлы и локальные коннекторы. |
| [RevEx.RevitPlugin](https://github.com/DenisFazlul/RevEx.RevitPlugin) | Текущий WPF-плагин Revit 2020: окно, панель и информация о документе. |

Документация соседних проектов находится в их корневых папках `docs`.
RevitPlugin пока не реализует HTTP-коннектор загрузки семейств: контракт и mock
коннектора находятся в Desktop, их нельзя считать готовой интеграцией плагина.

## Границы достоверности

Docker-стек, вход в веб и главное окно Desktop проверены 20.10.2026;
запрос каталога с обоими локальными пользователями вернул HTTP 200.
Запуск Revit и интеграция плагина не проверялись. Ранее встречавшееся описание
хранения каталога исключительно в памяти устарело: текущая конфигурация использует MongoDB и PostgreSQL.
